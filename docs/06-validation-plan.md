# Validation Plan — spend almost nothing before proving demand

Goal: replace the assumptions in docs/04 with real data for **<$2k**, then gate further spend.

## Phase 0 — Decisions (week 1)

- [ ] Pick niche + positioning (see docs/02 whitespace: pick ONE)
- [ ] Brand name shortlist → USPTO trademark search + domain/social handle check
- [ ] Form LLC (can defer to first-revenue gate if budget-tight)

## Phase 1 — Demand test, no inventory (weeks 1–4)

- [ ] One-page landing page (Shopify trial / Carrd): product render, positioning, email capture "Get launch access"
- [ ] 3–5 ad creatives (static + short video; UGC-style shot: chewing on the way to the gym)
- [ ] $500–1k TikTok/Meta spend at $30–50/day
- [ ] Track: CPC, waitlist opt-in rate, cost per signup

**Gates:**
| Metric | Continue if |
|---|---|
| Waitlist opt-in from click | > 10% (aim 25%+) |
| Cost per waitlist signup | < $5 |
| Qualitative | Comments show purchase intent ("where do I buy") |

## Phase 2 — Supply validation (parallel, weeks 1–4) — **the long pole for burst format**

- [ ] Request samples + quotes from **liquid-center/filled-gummy specialists** (co-extrusion lines, SiMoGel-type tech; several Asia-based exporters, US co-packers emerging) — ask: MOQ, per-piece cost, lead time, caffeine-in-core feasibility, melt/shell stability, CoA + Prop 65 docs, child-resistant packaging options
- [ ] Plain-gummy and softgel quotes as fallback comparison (softgels = fast MVP, loses candy magic)
- [ ] Order competitor samples (Energy Rocks, Jüced, SAVOR) → taste/dose teardown
- [ ] Get 1 regulatory consultant quote for label review

**Gate:** landed COGS ≤ $9/bottle equivalent at low MOQ with acceptable CoAs (burst format runs costlier than plain gummy — kill if way above).

## Phase 3 — Decision gate (week 5)

**Place first PO only if ALL true:**
- [ ] Waitlist ≥ 500 signups at < $5/signup
- [ ] Manufacturer quote ≤ $8/bottle landed
- [ ] Ad creatives found ≥ 1 winner (CTR/CPA sane)

## Phase 4 — Launch (weeks 6–12)

- [ ] First run: 500–1,000 bottles + single-serve pouch packs
- [ ] Seed 20–50 pouch packs to micro-creators in the niche (gym/college/relevant sport)
- [ ] Channels: TikTok Shop + Amazon + own store; subscription at ~$25/mo
- [ ] KPI: subscription attach ≥ 25%, blended CAC ≤ $35, review velocity on Amazon

## Kill / pivot criteria

- Demand test fails twice with different angles → kill or pivot audience
- COGS too high at low MOQ → pivot to single-serve pouch-only (lower unit commitment) or re-quote overseas with proper testing
- If a big incumbent floods the exact niche pre-launch → pivot niche, keep product
