# Full Timeline — Kitchen R&D → Co-Man → Launch

Merges the home-testing path (docs/09) with the demand-validation path (docs/06). Roughly 4–5 months to launch decision, ~$150 + ~$2k spent before any inventory commitment.

## Phase A — Kitchen R&D (weeks 1–4)

| Week | Milestone | Cost |
|---|---|---|
| −1 | Order kit (docs/11, ~$150); set up testing notebook + scales; read docs/08–09 safety sections | $150 |
| 1 | Shell experiments: gelatin gummy base + sour coating ratios (3:1, 2:1:½); basic (non-filled) texture pass | — |
| 2 | Core master syrup + two-pour assembly; deposit-weight log for dose consistency (±10% target); first complete burst piece | — |
| 3 | Flavor matrix: 3 flavors × 2 sour levels; 5-person taste panel with score cards → pick winner | — |
| 4 | Self-test protocol (docs/09): 1 → 2 → 4 pieces across a week; confirm tingle + smooth energy; recipe → v2 | — |

**Gate A:** a piece that bursts, sours, tingles, tastes good, and doses within ±10%.

## Phase B — Prove it survives + make it sellable-looking (weeks 5–6)

- [ ] Shelf test: fridge vs ambient (airtight), 14 days — leak, mold, sour-fade checks
- [ ] Isomalt hard-shell batch (stage 2) for the "Warheads crack" texture comparison
- [ ] Shoot content: burst reaction clips, sour-face clips, tingle explainer
- [ ] Write v3 spec sheet (piece weight, core formula, actives/serving, flavor targets, target COGS)

**Gate B:** recipe stable for 2 weeks; spec sheet + content exist.

## Phase C — Demand validation in parallel with co-man search (weeks 6–10, ≈ $1–2k)

Per docs/06: landing page + waitlist using Phase B content; $500–1k TikTok/Meta test; manufacturer samples & quotes (liquid-center specialists — the long pole).

Gates: waitlist opt-in >10% at < $5/signup; co-man landed COGS ≤ $9/bottle-equivalent.

## Phase D — Decision & build (weeks 10–16)

- [ ] Decision gate: waitlist ≥ 500 + COGS target met + ≥1 winning ad creative → place first PO (docs/06 Phase 3)
- [ ] Co-man pilot run with YOUR spec sheet (the home R&D cuts their R&D time — real value)
- [ ] Label review by regulatory consultant; child-resistant packaging; CoAs
- [ ] Launch: TikTok Shop + Amazon + DTC, creator seeding with pouch packs (docs/06 Phase 4)

## Kill criteria (unchanged)

- Kitchen R&D can't hit taste + tingle + burst after 4 weekends → format problem, pivot or kill
- No co-man under $9/bottle-equivalent for liquid-center → consider softgel-branded MVP or plain-gummy fallback
- Demand test fails twice with different angles → kill or pivot audience
