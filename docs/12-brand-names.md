# 12 — Brand Name Candidates & Screening (Draft)

**Status:** Draft — pre-screening only, NOT legal clearance.
**Date:** 2026-10-28
**Product:** Liquid-core burst candy pre-workout (sour shell / liquid energy core; caffeine + L-theanine + beta-alanine)
**Positioning:** "Pre-workout that explodes. Sour shell, energy core, and a tingle that says it's working."

**Naming constraints applied:** 1–2 words, punchy; evokes sour + burst + energy; clean to say in a gym ("chew two X and go"); no drug/steroid connotations; not juvenile-only; not Halloween-bound; no collision with Jüced, Energy Rocks, Trolli, Warheads, Gushers, Mocca Shots, 5-hour, Bucked Up, Ghost, C4.

**Method & confidence:**
- **Trademark:** web search of name + "trademark" / USPTO-adjacent sources (Justia/Trademarkia/trademarkelite snapshots + news). This catches registered and well-known common-law marks but is NOT a substitute for a full TESS/TSDR knock-out by counsel.
- **Domain:** `dig +short <name>.com A/NS` + `whois` (Verisign/registry "No match" = unregistered).
- **Social:** web search for exact handles / brand accounts on Instagram + TikTok. IG blocks deep indexing, so "not surfaced" = *likely* available, medium confidence. Verify in-app before committing.
- Graded A (clean on all three checks + strong fit) → F (direct category collision).

## 2. Ranked Top 5

1. **Puckershock — A−** — Clean trademark, clean social, and the .com is verifiably unregistered; "pucker" nails the sour-shell face-wrinkle and "shock" nails the hit, so the name literally performs the product.
2. **Repburst — A−** — Spotless on all three checks with the .com open, and it's native gym language ("rep" + burst) — the trade-off is it doesn't say *sour*, which the packaging/flavors must carry.
3. **Sourblitz — B+** — Sour + speed-of-hit in one word, .com available, only descriptive-adjacent uses (a Takis flavor name, one small candy shop) — slightly less punchy to shout than the top two.
4. **Zapburst — B+** — Clean everywhere socially and trademark-wise; only ding is zapburst.com is parked (zapburst.co and getzapburst.com are open) and it drops the sour cue.
5. **Voltburst — B** — Strong energy charge, clean trademark and socials, but the .com is a $3.5k marketplace listing (voltburst.co is open) and there's no sour signal.

*Watch-list (didn't make the five):* **Sourcore** (best semantic fit — sour + liquid core — but "SOUR CORE" is a live gamer energy drink name; revisit only if that SKU dies), **Shockpop** (fun, candy-coded; defunct comic-con LLC is the only mark in the way).

## 3. Recommendation

### 🏆 Puckershock

Chew two Puckershocks and go. It's the only candidate that lands **all three brand cues in one word** — pucker (sour shell), shock (energy hit), and the implied burst between them — while coming back clean on trademark search, social handles, and the .com (`puckershock.com` is unregistered today). It's TikTok-native without being juvenile, has zero Halloween dependency, and reads like a Warheads cousin without stepping on any live Warheads/CPG mark. Recommended next steps: file an intent-to-use application in Classes 5/30/32 after a formal TESS knock-out by counsel, and register `puckershock.com` + `getpuckershock.com` + `puckershock.co` immediately — availability is a snapshot, not a reservation.

## 4. Failed Names — Do Not Use

- **Pucker Punch** — live registered US trademark in **energy drinks** (Class 32, Upstate Beverage Holding, maintained through 2026) + Beam "PUCKER" enforcement precedent + AB InBev product line.
- **Sourboom** — existing **Warheads SourBoom** product; collides with an explicitly avoid-listed brand in candy.
- **Sourstrike** — Feastables "**Sour Strikes**" gummies national rollout (Target/7-Eleven, Sept 2025) + RAFFA "Sour Strike Belts"; crowded by a well-funded candy major.
- **Liquicore** — live liquid-supplement use (NZN "LiquiCore Curmin") in the same broad category, plus industrial ™ holders; previously-registered mark abandoned but the field isn't clear.
